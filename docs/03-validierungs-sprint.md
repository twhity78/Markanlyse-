# Validierungs-Sprint (7 Tage)

**Ziel:** Bevor eine Zeile Code geschrieben oder ein Tool gebaut wird,
beweisen, dass echte Menschen für deine Marktanalyse zahlen würden.

**Erfolgskriterium:** Mindestens **1 Person sagt "Ja, das würde ich kaufen"
zu einem konkreten Preis** — idealerweise 3.

> Das Dokument nennt es den Unterschied zwischen Konsument und Integrator:
> Integratoren verkaufen zuerst und bauen danach.

## Tag 2–3: Ein Demo-Beispiel erstellen (mit Claude, ohne Code)

Erstelle EINEN beispielhaften Marktanalyse-Report für eine fiktive oder
echte Firma aus deiner Nische. Das ist dein Verkaufsargument.

**Prompt-Vorlage für Claude:**

```text
Erstelle einen professionellen Marktanalyse-Report (3–4 Seiten) für
[BEISPIELFIRMA] in der Branche [NISCHE], Region [REGION].

Struktur:
1. Executive Summary (5 Kernaussagen)
2. Marktumfeld & Trends (was verändert sich gerade?)
3. Wettbewerbslandschaft (wer sind die 5 wichtigsten Wettbewerber,
   was machen sie gut/schlecht?)
4. Chancen & Risiken (konkret und priorisiert)
5. 3 Handlungsempfehlungen

Stil: sachlich, datenorientiert, für einen Geschäftsführer ohne
Analysten-Hintergrund lesbar. Kennzeichne Annahmen klar als Annahmen.
```

Dann: In ein sauberes PDF gießen (Google Docs oder Canva reicht).

> ⚠️ **Wichtig:** Kennzeichne im Demo-Report, dass KI-generierte Zahlen
> vor Kundeneinsatz gegen echte Quellen geprüft werden. Genau diese
> Prüf- und Veredelungsarbeit ist später dein Mehrwert gegenüber
> "der Kunde fragt einfach selbst ChatGPT".

## Tag 3–6: Gespräche führen

Kontaktiere mindestens 5 Personen von deiner Liste. Vorlage:

```text
Hallo [NAME],

ich baue gerade einen Service auf, der [NISCHE]-Unternehmen
automatisierte Markt- und Wettbewerbsanalysen liefert — als
monatlicher Report statt teurer Einmal-Beratung.

Ich habe ein Beispiel erstellt und würde dir gern 15 Minuten
zeigen, wie so etwas für [FIRMA] aussähe. Keine Verkaufsshow —
ich will ehrliches Feedback, ob das nützlich wäre.

Hättest du diese Woche kurz Zeit?
```

**Im Gespräch — die 4 Pflichtfragen:**

1. "Wie triffst du heute Entscheidungen über [Preise/Standorte/Wettbewerb]?"
2. "Was würde dir so ein Report konkret ersparen oder bringen?"
3. "Was müsste drinstehen, damit er wirklich nützlich ist?"
4. **Die Geldfrage:** "Wenn das jeden Monat aktuell in deinem Postfach läge —
   wäre dir das z. B. 300 € im Monat wert? Falls nein: welcher Betrag?"

**Notiere wörtlich, was gesagt wird** — besonders Einwände.

## Tag 7: Auswerten und entscheiden

| Ergebnis | Bedeutung | Nächster Schritt |
|----------|-----------|------------------|
| ≥ 3 konkrete Kaufzusagen | Starke Validierung | Direkt zum [No-Code MVP](04-no-code-mvp.md), erste Pilotkunden onboarden |
| 1–2 Zusagen / starkes Interesse | Brauchbar | MVP bauen, Angebot anhand der Einwände schärfen |
| Nur höfliches Interesse, niemand nennt einen Betrag | Schwach | Nische oder Produkt wechseln — zurück zum [Nischenfinder](02-nischenfinder.md), Kandidat B testen |
| Absagen mit klarer Begründung | Wertvoll! | Begründungen sind deine Marktforschung — Pivot mit diesem Wissen |
